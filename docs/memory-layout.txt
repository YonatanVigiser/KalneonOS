Low mem:

00000 - 004FF: BIOS reserved memory (1.25KB)
00500 - 026FF: Boot1 code (8.5KB)
02700 - 04FFF: Boot info (mostly unused mem) (10.25KB)
05000 - 07BFF: Real-mode stack (mostly unused mem) (11KB)
07C00 - 07DFF: Boot0 code (0.5KB)
07E00 - 77FFF: Free mem (448.5KB)
78000 - 7FFFF: Kernel copy buffer (32KB)
80000 - 8FFFF: Protected mode stack (mostly unused mem) (64KB)
90000 - FFFFF: BIOS code (448KB)

High mem:

100000 - 1FFFFF: Kernel code (1MB)
200000 - 2FFFFF: Kernel data (1MB)
300000 - 3FFFFF: Kernel stack (1MB)
